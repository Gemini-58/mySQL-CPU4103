# Database Design Diagrams – Crownfield Eye Hospital

This folder contains the three database design diagrams created for the CPU4:103 Database Development assignment.

## 1. Conceptual Data Model
Shows the main entities and relationships identified from the Crownfield Eye Hospital scenario.

## 2. Logical Data Model
Shows the entities, attributes, primary keys, foreign keys and relationships.

## 3. Final Relational Schema
Shows the final database tables, primary keys, foreign keys and relationships after normalisation.

## Software Used
All diagrams were created using Draw.io (diagrams.net).

## How to View
Download any `.drawio` file and open it using https://app.diagrams.net/.
